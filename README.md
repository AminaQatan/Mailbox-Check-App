## Publish on GitHub Pages

1. Extract this ZIP on your phone or computer.
2. Open https://github.com/new and create a **Public** repository named **Kind-message**. Add a README when creating it so the `main` branch exists.
3. In the repository, choose **Add file → Upload files**. Upload all the extracted files, including `index.html`, `styles.css`, `app.js`, `messages.js`, and `icon.svg`. Upload the contents directly into the repository, not the ZIP or an enclosing folder. Commit the changes.
4. Go to **Settings → Pages**. Under Source choose **Deploy from a branch**, then choose **main** and **/(root)**, and click **Save**.
5. Once the deployment finishes, GitHub shows the live link under Pages. Share that link with students.

The app has no sign-in screen. GitHub Pages serves this version directly. No paid service, API key, build command or database is required.

Official publishing guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## خطوات النشر بالعربية

1. فكّ ضغط ملف ZIP.
2. أنشئ مستودعًا عامًا (Public) باسم Kind-message في GitHub، مع إضافة README.

## What is included

- Mobile-friendly rose, pink and lavender stationery design.
- English and Arabic interface and 24 bilingual encouragement notes.
- Name-based greetings, animated envelope and gentle sounds.
- Read aloud using available device/browser voices.
- Save a personal message as a PNG card.

## Edit and run

- `index.html`: page layout and app title.
- `styles.css`: colours, typography, envelope and responsive layout.
- `app.js`: translations, name handling, message selection, sounds, reading aloud and card export.
- `messages.js`: all 24 English/Arabic notes. Edit these to change the messages.
- `icon.svg`: app favicon.
- `.nojekyll`: static hosting marker; this plain HTML app also works without it.

Open `index.html` for a local preview, or serve this folder with a static web server. The app uses relative paths and works in a GitHub repository subdirectory.

Message selection stays consistent for the same name; different names may receive the same note. No student names or messages are stored by application code. Only the language and sound preferences are stored in the browser. Read-aloud availability depends on installed device/browser voices. Google Fonts loads fonts when available; local fallback fonts are used otherwise. Sounds are generated in the browser. The app has no API, database, login, or server dependency.

If the repository is renamed later, use the new link shown in Settings → Pages.
